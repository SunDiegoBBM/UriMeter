## Quick Start Tutorial

1. **Launch** `urimeter_app.exe` (It's a portable One-File Executable — no installation needed, Tesseract is built-in!).
2. **Click `[+] CALIBRATE RADAR`** and draw a tight box *only* around your Uridium balance on the screen.
3. **Hit `INITIATE`** to start the engine. It will lock your base Uri and track automatically.
4. *(Optional)* Enter a target amount and click **`LOCK ETA`** to track your farming progress.
5. Click **`▼ COMPACT HUD`** to hide the main window and keep only the essential stats visible.
6. Use **`HALT`** to pause or **`PURGE`** to reset your session stats.
